# Site100 v2 고도화

## 목표

v1의 100개 디자인 지문을 유지하면서 갤러리를 단순 목록이 아닌 **디자인 탐색·비교·맞춤 설정 도구**로 확장합니다. 개별 홈페이지는 업종별 데모를 보는 단계에서 실제 고객에게 제안할 수 있는 템플릿 프레젠테이션 단계로 고도화합니다.

## 갤러리 개선

1. 업종·레이아웃·분위기·인터랙션을 동시에 선택할 수 있습니다.
2. 검색과 필터 상태를 URL 쿼리에 저장해 같은 결과를 공유할 수 있습니다.
3. 업종·분위기·전환 행동을 입력하면 점수가 높은 디자인 세 개를 추천합니다.
4. 즐겨찾기와 최근 방문 기록은 브라우저 `localStorage`에 저장됩니다.
5. 세 개의 디자인을 Hero·레이아웃·타입·분위기·인터랙션 기준으로 비교할 수 있습니다.
6. 모든 사이트에 고유 SVG 미리보기를 빌드 시 생성합니다.
7. `/` 키로 검색창에 이동하고 `R` 키로 현재 필터 안에서 무작위 디자인을 엽니다.

## 개별 홈페이지 개선

1. 모바일 메뉴, 활성 섹션 표시, 스크롤 진행률을 제공합니다.
2. 데스크톱·태블릿·모바일 폭을 즉시 전환해 확인할 수 있습니다.
3. 브랜드명, 강조색 두 개, 정보 밀도와 고대비를 브라우저 안에서 변경할 수 있습니다.
4. 맞춤 설정을 JSON으로 저장하고 현재 템플릿의 기획서를 복사할 수 있습니다.
5. 문의 폼은 실제 전송 대신 초안을 만들고 복사하거나 TXT로 저장합니다.
6. 같은 업종·분위기·인터랙션을 기준으로 관련 디자인 세 개를 제안합니다.
7. 이전·다음 세계와 전체 갤러리로 빠르게 이동할 수 있습니다.
8. `prefers-reduced-motion`과 사용자의 모션 감소 설정을 반영합니다.

## SEO·배포 개선

- 사이트별 `WebSite` 구조화 데이터
- 갤러리 `CollectionPage`·`ItemList` 구조화 데이터
- 고유 title, description, canonical, Open Graph, Twitter Card
- SVG 미리보기 100개와 갤러리 대표 이미지
- web manifest, SVG 아이콘, robots, sitemap, 404, offline 페이지
- `design.json` v2 콘텐츠 지문

## 자동 검사

- 홈페이지·독립 URL·design.json·SVG 미리보기 각각 정확히 100개
- ID, slug, 디자인 지문, 팔레트, 업종 콘텐츠 지문 중복 금지
- 업종 분야별 정확히 10개
- 25개 레이아웃 CSS, 23개 인터랙션 렌더러 확인
- v2 기능 함수·CSS 존재 여부
- 생성 페이지의 title·canonical·구조화 데이터·OG·Twitter·manifest 확인
- SVG 미리보기 해시 중복 검사
