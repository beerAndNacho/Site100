# Site100 v3 · Art Direction System

## 문제 정의

v2까지는 25개 레이아웃, 20개 Hero, 23개 인터랙션과 고유 팔레트가 있었지만, 본문 카드·작업물·추상 도형의 표현 방식은 일정 부분 공통이었습니다. v3의 목표는 컴포넌트를 무작정 100벌로 복제하는 것이 아니라, **업종군마다 서로 다른 시각 문법을 부여하고 각 홈페이지의 실제 소재가 Hero와 표면에 나타나게 만드는 것**입니다.

## 10개 시각 방향

### 001–010 · Atelier

지역 매장과 생활 서비스에 적용합니다.

- 종이 카드와 스탬프
- 약간 비뚤어진 배치
- 수공예 그림자
- 업종 사물을 라벨·티켓처럼 표현
- CTA의 물리적인 눌림과 오프셋 그림자

### 011–020 · Precision

전문 서비스와 B2B에 적용합니다.

- 청사진형 그리드
- 치수선과 좌표
- 얇고 정밀한 정보선
- 직각 프레임과 번호 체계
- 신뢰감 있는 명암 대비

### 021–030 · Interface

SaaS와 기술 서비스에 적용합니다.

- 반투명 유리 패널
- 데이터 노드와 발광 경로
- 짧은 모서리 반경과 깊은 그림자
- 스캔 그리드와 포인터 조명
- 시스템 상태를 연상시키는 마이크로카피

### 031–040 · Notebook

교육과 지식 서비스에 적용합니다.

- 공책의 가로선과 여백선
- 형광펜 라벨
- 메모지와 주석
- 직접 작성한 듯한 회전
- 과정과 커리큘럼 중심의 리듬

### 041–050 · Organic

웰니스와 케어 서비스에 적용합니다.

- 유기적인 곡선
- 호흡하는 듯한 넓은 여백
- 둥근 표면과 블러
- 부드러운 색상 혼합
- 모션 감소 환경에서도 안정적인 정적 형태

### 051–060 · Studio

문화와 창작 서비스에 적용합니다.

- 필름 프레임과 콘택트 시트
- 크롭 마크
- 콜라주와 불균형한 정렬
- 대형 편집 타이포
- 이미지 장면을 강조하는 오프셋 그림자

### 061–070 · Atlas

여행과 숙박 서비스에 적용합니다.

- 등고선
- 경로와 좌표
- 위치 표식
- 수평선·아치형 프레임
- 이동 과정과 장소를 연결하는 섹션 흐름

### 071–080 · Catalog

음식·소비재·라이프스타일에 적용합니다.

- 제품 진열대
- 스와치와 라벨
- 촉감 있는 카드
- 둥근 상품 표면
- 메뉴·옵션·주문 흐름 강조

### 081–090 · Civic

공공·비영리·커뮤니티 서비스에 적용합니다.

- 굵은 정보 블록
- 공공 포스터
- 높은 대비
- 분명한 번호와 CTA
- 접근 가능한 읽기 순서

### 091–100 · Experimental

개인·행사·실험적 사이트에 적용합니다.

- 겹치는 윈도
- 혼합 모드
- 비정형 클리핑
- 왜곡된 그리드와 타이포
- 예상 밖의 섹션 오프셋

## 고유 SVG 아트워크

`npm run build` 실행 시 `scripts/art-build.mjs`가 다음을 수행합니다.

1. 100개 홈페이지의 업종군을 10개 아트 디렉션에 매핑합니다.
2. 브랜드명, 업종, 팔레트, 실제 소재와 사이트 번호를 SVG에 반영합니다.
3. 사이트별 seed로 위치·크기·회전·경로를 달리합니다.
4. `dist/artworks/<slug>.svg`에 100개를 생성합니다.
5. SHA-256 해시를 비교해 중복 아트워크를 차단합니다.
6. 각 `design.json`에 `visualVersion`, `artDirection`, `artwork`를 기록합니다.

## 런타임 표현

`src/art-direction.js`는 기본 페이지가 렌더링된 뒤 다음 요소를 추가합니다.

- Hero 아트 스테이지
- 포인터 기반 패럴랙스
- 제목 단어 등장
- 소재 마키
- 섹션별 시각 리듬
- 현재 섹션 레일
- 카드 표면의 포인터 조명
- 관련 작품의 깊이감
- 대형 Footer 스테이트먼트
- 갤러리 대표 디자인 런웨이

## 성능·접근성 원칙

- 아트워크는 외부 이미지 요청 없이 정적 SVG로 생성합니다.
- 모바일에서는 Hero 아트를 문서 흐름 안으로 이동시킵니다.
- `prefers-reduced-motion`일 때 패럴랙스·마키·등장 모션을 정지합니다.
- 커스텀 커서는 정밀 포인터 환경에서만 동작합니다.
- 모든 SVG에는 `<title>`과 `<description>`을 포함합니다.
- 아트 디렉션 레이어가 실패해도 기존 v2 페이지와 인터랙션은 유지됩니다.

## 자동 감사

`npm run audit`은 기존 경로·SEO·카피 검사와 함께 다음을 확인합니다.

- 아트워크 100개
- 아트워크 해시 중복 0건
- 아트 디렉션 10종 × 각 10개
- HTML의 v3 CSS·런타임 연결
- `design.json`의 v3 메타데이터
- 갤러리와 개별 페이지의 v3 자산
- Hero, 소재 마키, 섹션 레일, 런웨이 등 핵심 시각 컴포넌트
