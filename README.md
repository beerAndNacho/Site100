# Site100 · 100WORLDS

서로 다른 업종과 목적을 가진 홈페이지 디자인 100개를 한 저장소에서 제작하고 검증하는 정적 웹 프로젝트입니다.

- 갤러리: `https://beerandnacho.github.io/Site100/`
- 개별 사이트: `https://beerandnacho.github.io/Site100/sites/<slug>/`
- 전체 목록: [`docs/SITES-100.md`](docs/SITES-100.md)

## 다양성 기준

각 사이트는 25가지 레이아웃, 10가지 내비게이션, 20가지 Hero, 10가지 타이포 방향, 10가지 형태, 10가지 시각 매체, 5가지 밀도, 10가지 분위기, 23가지 인터랙션과 100가지 고유 팔레트를 조합한 독립 디자인 지문을 가집니다.

100개가 서로 다른 프레임워크를 사용하는 것은 아닙니다. 접근성·반응형·인터랙션 엔진은 공유하지만 업종 소재, Hero 구조, 화면 흐름, 디자인 지문과 독립 URL은 모두 다르게 구성합니다.

```bash
npm run check
npm run build
```
